# Як отримати установочний файл для Windows через GitHub

Усе вже підготовлено: ядро (C++), програма (Tauri) і файл збірки `.github/workflows/build-windows.yml`.
GitHub сам візьме віртуальний комп'ютер з Windows, збере ядро, завантажить нейромережі й створить інсталятор `.exe`
з усім потрібним усередині (окремо нічого встановлювати користувачу не треба).

## 1. Створіть репозиторій
1. На https://github.com натисніть **New repository**, назва, наприклад, `beatpractice`. Виберіть **Private** (приватний).
2. Не додавайте README/.gitignore (залиште репозиторій порожнім).

## 2. Завантажте код
Розпакуйте архів і в терміналі в теці, де лежать `beat-core`, `BeatPractice` та прихована тека `.github`:
```
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/beatpractice.git
git push -u origin main
```
(Завантажувати через браузер не радимо: прихована тека `.github` часто губиться.)

## 3. Запустіть збірку
1. У репозиторії відкрийте вкладку **Actions**.
2. Ліворуч виберіть **Windows installer** → **Run workflow** → **Run workflow**.
3. Перша збірка триває 25–50 хвилин (потім швидше, бо кешуються Rust і нейромережі).

## 4. Заберіть інсталятор
Коли збірка стане зеленою: відкрийте її та внизу в розділі **Artifacts** завантажіть
`BeatPractice-Windows-installer` (zip з файлом `BeatPractice_1.0.0_x64-setup.exe`). Запустіть його на Windows.
Windows SmartScreen може показати попередження, бо програма не має цифрового підпису: **Докладніше → Все одно запустити**.

## Якщо збірка червона
Відкрийте її, натисніть на крок, біля якого червоний хрестик, і скопіюйте кілька останніх десятків рядків журналу.
- Помилка на кроці **Build core**: проблема компіляції C++ на Windows (ядро я перевіряв крос-компіляцією, але не справжнім MSVC).
- Крок **Core smoke test** може бути жовтим: він необов'язковий і збірку не зупиняє.
- Помилка на **Download models**: тимчасово недоступний сервер із моделями, просто повторіть запуск.
- Помилка на **Build installer**: надішліть журнал.

## Де програма зберігає дані
Результати аналізу пісень (кеш) лежать у `%LOCALAPPDATA%\com.beatpractice.app\cache`.

## Новинка: експорт треку
Кнопка зі стрілкою вниз поруч із назвою треку зберігає WAV із поточним темпом і вимкненими партіями
(за бажанням разом із метрономом). Партії мають бути розділені на вкладці «Розділення партій».

## Оновлення вже створеного репозиторію (папка перейменована на BeatPractice)
У теці репозиторію на комп'ютері видаліть старі `ritmtrener-tauri`, `beat-core` і `.github`, розпакуйте на їхнє місце нові теки з архіву й виконайте:
```
git add -A
git commit -m "BeatPractice update"
git push
```
Сам репозиторій на GitHub можна перейменувати: **Settings → General → Repository name → `beatpractice`**. Старе посилання продовжить працювати.
Перед установленням нової версії видаліть стару «RitmTrener» у «Встановлення та видалення програм»; нова називається BeatPractice і зберігає кеш в іншій теці.

## Версія 1.0
- Програма встановлюється для всіх користувачів у `C:\Program Files\BeatPractice` (Windows попросить дозволу адміністратора).
- Якщо раніше встановлювали попередню збірку, спершу видаліть її в «Встановлення та видалення програм».
- Системний рядок заголовка вікна на Windows прибрано; кнопки «Згорнути / Розгорнути / Закрити» тепер у верхній смузі програми.

## Підготовка до продажу
- **Ліцензійна угода** (`BeatPractice/src-tauri/legal/EULA.txt`) показується в інсталяторі й у вікні «Про програму» (кнопка «i» під плейлістом). Це шаблон, його варто показати юристу.
- **Сторонні компоненти:** `THIRD_PARTY_NOTICES.txt` + автоматичні повні списки пакетів (`licenses-rust.txt`, `licenses-npm.txt`) лягають у теку `legal` поруч із програмою.
- **Ваше ім'я** вказано як «Mike» у `src/components/AboutDialog.tsx`, `src-tauri/legal/*.txt` та `src-tauri/tauri.windows.conf.json` (поля publisher і copyright). Замініть на потрібне, якщо треба повне ім'я чи назву компанії.
- **Копії нейромереж у власному репозиторії:** один раз запустіть у вкладці Actions робочий процес **Mirror models**. Далі збірка бере моделі з вашого релізу `models-v1`, а якщо їх там немає, з оригінальних джерел.

## Розділення на 6 партій (гітара й піаніно окремо)
Програма тепер бере модель HT-Demucs на 6 партій: ударні, бас, інше, вокал, гітара, піаніно. 4-партійна модель теж лежить в інсталяторі й вмикається автоматично, якщо 6-партійну неможливо завантажити. Перший розподіл кожної пісні відбувається заново (кеш старої моделі не підходить).
У журналі збірки крок **Probe the stem model** покаже, скільки партій дає модель (очікується 6).
