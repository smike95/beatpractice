# Дизайн-система BeatPractice: кольори

Усі кольори інтерфейсу — це **ролі**. Кожна роль має по одному значенню для темної й світлої теми (`src/index.css`, змінні `--c-*` і `--accent*`). Класи пишуться один раз і працюють в обох темах, також із прозорістю (`bg-canvas/60`).

## Нейтральні ролі (Tailwind-класи)

| Роль | Класи | Для чого |
|---|---|---|
| canvas | `bg-canvas` | вікно; поля вводу й заглиблені ділянки всередині картки |
| surface | `bg-surface` | картки, панелі, бічна панель, діалоги |
| control | `bg-control`, `hover:bg-control-hover`, `bg-control-active` | кнопки, сегменти, чипи; hover і обраний варіант; найсильніша нейтральна заливка |
| line | `border-line`, `divide-line` | тонкі розділювачі навколо блоків |
| outline | `border-outline` | контури кнопок і полів (у світлій темі контраст 3:1) |
| ink | `text-ink`, `text-ink-2`, `text-ink-3`, `text-ink-4` | текст: основний, другорядний, приглушений, ледь помітний |

## Акцент

`bg-accent`, `hover:bg-accent-hover`, `text-accent-text`, `border-accent`, `ring-accent`, `bg-accent/15`, текст на заливці — `text-accent-on`.
За замовчуванням: фіолетовий у темній темі й синій у світлій. Список «Акцент» (тимчасовий, `src/utils/accent.ts`) підставляє один системний колір Apple для обох тем: основний, hover (Light Vibrant / Dark plus lighter) і колір тексту на заливці. Значення — точні свотчі з macOS 27 UI Kit.

## Правила

1. Не писати `slate-*`, `dark:` і жорсткі hex у компонентах. Потрібен новий колір — додати роль у `index.css` і `tailwind.config.js`.
2. Обраний стан (вкладка, сегмент, обкладинка, кнопка «є що зробити») — акцент в обох темах (`.tab-active`, `.seg-on`, `.cover-ph-active`, `.btn-attn`).
3. Канва хвилі читає акцент через `useAccentRgb()`; кольори петель — окрема палітра `LOOP_PALETTE` у `types.ts`.
4. Правила `html.light …` у CSS — лише для справжніх відмінностей теми (тінь, роздільник заголовка), не для перефарбування класів.
