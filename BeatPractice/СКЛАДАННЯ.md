# BeatPractice: як зібрати програму на іншому комп'ютері

Цей архів містить **увесь код програми** (інтерфейс і Rust-оболонка Tauri). Звук, аналіз ритму й розділення на партії робить ядро з архіву `beat-core-full.zip` (збирається окремо, див. його `СКЛАДАННЯ.md`).

## 1. Потрібно мати
- **Node.js** (LTS, v20 і новіше): https://nodejs.org
- **Rust**: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh` (потім відкрийте новий Термінал; перевірка: `cargo --version`)
- **macOS:** Xcode Command Line Tools (`xcode-select --install`). **Windows:** Microsoft C++ Build Tools і WebView2. **Linux:** `webkit2gtk-4.1`, `libgtk-3-dev` та інші залежності Tauri (https://tauri.app/start/prerequisites/).

## 2. Ядро
Спершу зберіть ядро за інструкцією в `beat-core-full.zip` (потрібні `build/libbeatcore_c.dylib` і тека `models/`).

## 3. Запуск для розробки
```
cd BeatPractice
npm install
npm run tauri dev
```
Перший запуск збирає Rust-частину (5–15 хвилин). При першому запуску програма попросить обрати теку `beat-core`.

## 4. Готова програма (необов'язково)
```
npm run tauri build
```
Готовий застосунок з'явиться в `src-tauri/target/release/bundle/`. Зверніть увагу: теку `beat-core` програма шукає там, де ви її вкажете при першому запуску; вбудовування ядра всередину `.app` ще не зроблено.

## 5. Перевірка (необов'язково)
- Інтерфейс: `npx tsc --noEmit` і `npx vite build`
- Rust: `cd src-tauri && cargo test --lib`
