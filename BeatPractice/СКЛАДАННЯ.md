# BeatPractice: збірка на власному комп'ютері

Зазвичай установочні файли збирає GitHub (див. `../ІНСТРУКЦІЯ-GITHUB.md`). Тут описано локальну розробку й ручну збірку.
Звук, аналіз ритму й розділення на партії робить ядро з теки `../beat-core` (збирається окремо, див. `../beat-core/СКЛАДАННЯ.md`).

## 1. Потрібно мати
- **Node.js** (LTS, v20 і новіше): https://nodejs.org
- **Rust**: https://rustup.rs (після встановлення відкрийте новий термінал; перевірка: `cargo --version`)
- **Windows:** Visual Studio Build Tools із компонентом «Desktop development with C++», WebView2 (є у Windows 10/11).
- **macOS:** Xcode Command Line Tools (`xcode-select --install`).
- **Linux:** `webkit2gtk-4.1`, `libgtk-3-dev` та інші залежності Tauri (https://tauri.app/start/prerequisites/).

## 2. Ядро
Зберіть `beat-core` і завантажте нейромережі за його інструкцією. Потрібні файл `build/beatcore_c.dll` (Windows) або `build/libbeatcore_c.dylib` (macOS) і тека `models/`.

## 3. Запуск для розробки
```
cd BeatPractice
npm install
npm run tauri dev
```
Перший запуск збирає Rust-частину (5–15 хвилин). Програма попросить указати теку `beat-core`.

## 4. Інсталятор вручну (необов'язково)
Ядро й нейромережі потрапляють в інсталятор з теки `src-tauri/core-bundle/`. Наповніть її так само, як це робить збірка в GitHub:
- **Windows:** `core-bundle/build/` ← `beatcore_c.dll`, `onnxruntime.dll` і `vcruntime140.dll`, `vcruntime140_1.dll`, `msvcp140.dll` (з `C:\Windows\System32`);
- **macOS:** `core-bundle/build/` ← `libbeatcore_c.dylib` і справжній (з номером версії) `libonnxruntime.*.dylib`; потім `install_name_tool -add_rpath @loader_path libbeatcore_c.dylib` і `codesign --force --sign - *.dylib`;
- **обидві системи:** `core-bundle/models/` ← файли `*.onnx` з `beat-core/models`.

Далі `npm run tauri build`. Результат: `src-tauri/target/release/bundle/` (Windows: `nsis/*.exe`, macOS: `dmg/*.dmg`).

## 5. Перевірка (необов'язково)
- Інтерфейс: `npx tsc --noEmit` і `npx vite build`
- Rust: `cd src-tauri && cargo test --lib`
