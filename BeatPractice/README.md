# BeatPractice

Програма для практики гри під музику: розпізнає долі й такти пісні, дає метроном, зміну темпу без зміни висоти тону, цикли й розділення на партії.
Інтерфейс: React + Tailwind у вікні Tauri. Звук і аналіз робить C++ ядро `beat-core` (підключається під час роботи як бібліотека).

## Що вміє
- **Верхня смуга** (завжди на місці): емблема з назвою над плейлістом; праворуч експорт, ⏮ ▶/Пауза ⏭ і кнопка «що робити після кінця» (зупинитись / знову цей трек з відліком / наступний трек). На Windows тут же кнопки вікна.
- **Плейліст:** додавання кнопкою або перетягуванням файлів, зміна порядку «ручкою», видалення з підтвердженням, обкладинки, дані треку (виконавець, назва, обкладинка), тема й мова внизу, кнопка «Про програму».
- **Картка треку:** темп оригіналу, розмір (змінний показується як «4/4, 3/4»), керування темпом, Клік / Акцент / Відлік, візуальні долі, мікшер (трек і клік).
- **Хвиля:** сітка долей, номери тактів, мінікарта, секції, цикл. Масштаб кнопками −/+ (крок ×1,25, до ×32), швидкі ×1 ×2 ×4 ×8 і Ctrl + колесо. Під час програвання при масштабі більше ×1 позначка доходить до середини, далі рухається хвиля, на кінці знову позначка. Хвилю можна гортати смугою чи жестом, кнопка «Слідкувати» повертає слідування. Цикл, який вміщується в зону, стоїть на місці.
- **Вкладки:** *Метроном та темп* (відлік, звук метронома, розпізнавання розміру, карта темпу), *Тренування* (до 3 циклів, відлік перед кожним повтором), *Розділення партій* (ударні, бас, інше, вокал, гітара, піаніно; тумблер і рівень кожної партії, швидкі набори).
- **Під час першого аналізу** треку можна слухати оригінал.
- **Експорт** у WAV із поточним темпом і вимкненими партіями (за бажанням разом із метрономом).
- Одна копія програми одночасно, вікно «Про програму» з ліцензійною угодою й переліком сторонніх компонентів.
- Три розміри шрифту на весь інтерфейс (15, 19, 28 px); акцентний колір фіолетовий у темній темі й блакитний у світлій.

## Будова
- `src/App.tsx`: розмітка; `src/components/`: панелі й вікна; `src/player/usePlayer.ts`: стан програвача й зв'язок з ядром; `src/core.ts`: виклики Rust.
- `src-tauri/src/lib.rs`: команди для інтерфейсу; `src-tauri/src/core.rs`: підключення бібліотеки `beat-core` (`beatcore_c.dll` / `libbeatcore_c.dylib`).
- `src-tauri/tauri.conf.json`: загальні налаштування; `tauri.windows.conf.json` і `tauri.macos.conf.json`: налаштування інсталяторів.
- `src-tauri/legal/`: ліцензійна угода й сторонні компоненти. `src-tauri/core-bundle/`: сюди збірка кладе ядро й нейромережі, щоб вони потрапили в інсталятор (у репозиторії там лише `README.txt`).

## Запуск для розробки
Потрібні Node.js (LTS) і Rust (див. `СКЛАДАННЯ.md`).
```
cd BeatPractice
npm install
npm run tauri dev
```
У режимі розробки програма попросить указати теку `beat-core` (де є `build/` і `models/`). У встановленій програмі ядро береться з самого інсталятора.

Установочні файли для Windows і macOS збирає GitHub, див. `../ІНСТРУКЦІЯ-GITHUB.md`.
