# beat-core: збірка

Тека містить **увесь код ядра** (аудіо, аналіз ритму, розділення на партії, експорт, тести). Нейромережі й ONNX Runtime не входять (дуже великі), їх завантажують скрипти й команди нижче.
Установочні файли програми збирає GitHub (див. `../ІНСТРУКЦІЯ-GITHUB.md`); тут описано ручну збірку ядра.

## 1. Потрібно мати
- **Windows:** Visual Studio Build Tools («Desktop development with C++»), CMake, Git (для скриптів `sh`, достатньо Git Bash).
- **macOS:** Xcode Command Line Tools (`xcode-select --install`) і CMake (`brew install cmake`).
- **Linux:** `g++`, CMake.
- Інтернет для завантаження моделей (один раз).

## 2. Нейромережі (з теки beat-core)
```
sh scripts/fetch_models.sh          # аналіз ритму, ~94 МБ
sh scripts/fetch_stem_model.sh      # розділення на 6 партій, ~136 МБ (можна пропустити, тоді розділення недоступне)
sh scripts/fetch_stem_model.sh --four   # необов'язково: 4-партійна модель як запасна, ~166 МБ
```

## 3. ONNX Runtime 1.22.0
Завантажте з https://github.com/microsoft/onnxruntime/releases/tag/v1.22.0 пакет **для вашої системи й процесора** і розпакуйте:
- Windows: `onnxruntime-win-x64-1.22.0.zip`
- macOS на Apple Silicon (`uname -m` = `arm64`): `onnxruntime-osx-arm64-1.22.0.tgz`
- macOS на Intel (`x86_64`): `onnxruntime-osx-x86_64-1.22.0.tgz`
- Linux: `onnxruntime-linux-x64-1.22.0.tgz`

## 4. Збірка
**macOS / Linux:**
```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DORT_DIR=/шлях/до/розпакованого/onnxruntime
cmake --build build
```
(на macOS додайте `-DCMAKE_OSX_ARCHITECTURES=arm64` або `x86_64`, за процесором.) Результат: `build/libbeatcore_c.dylib` (Linux: `.so`).

**Windows** (у «x64 Native Tools Command Prompt for VS» або PowerShell):
```
cmake -S . -B build -DORT_DIR=C:\шлях\до\onnxruntime-win-x64-1.22.0
cmake --build build --config Release --target beatcore_c
```
Результат: `build\Release\beatcore_c.dll`. Поруч треба покласти `onnxruntime.dll` (з `onnxruntime-win-x64-1.22.0\lib`).

## 5. Перевірка (необов'язково)
Зберіть тести (`cmake --build build`, на Windows додайте `--config Release`) і запустіть:
```
./build/meter_test tests/data/meter       # має закінчитись ALL PASSED
./build/stems_engine_test                 # ALL PASSED
./build/sounds_test                       # ALL PASSED
./build/engine_test                       # ENGINE TEST PASSED
./build/stems_cli --probe --model models/htdemucs_6s_fp16weights.onnx   # показує кількість партій моделі
```
На Windows запускайте `build\Release\*.exe` (поруч має лежати `onnxruntime.dll`).
