# beat-core: як зібрати на іншому комп'ютері

Цей архів містить **увесь код ядра** (аудіо, аналіз ритму, розділення на партії, тести). Не входять нейромережі й ONNX Runtime (вони завантажуються скриптами нижче), бо дуже великі.

## 1. Потрібно мати
- **macOS:** Xcode Command Line Tools (`xcode-select --install`) і CMake (`brew install cmake` або з https://cmake.org).
- Інтернет для завантаження моделей (один раз).

## 2. Нейромережі (з теки beat-core)
```
sh scripts/fetch_models.sh          # аналіз ритму, ~94 МБ
sh scripts/fetch_stem_model.sh      # розділення на партії, ~166 МБ (можна пропустити, тоді розділення буде недоступне)
```

## 3. ONNX Runtime
Завантажте з https://github.com/microsoft/onnxruntime/releases/tag/v1.22.0 пакет **для вашого процесора** і розпакуйте:
- Mac на Intel (`uname -m` показує `x86_64`): `onnxruntime-osx-x86_64-1.22.0.tgz`
- Mac на Apple Silicon (`arm64`): `onnxruntime-osx-arm64-1.22.0.tgz`
- Windows: `onnxruntime-win-x64-1.22.0.zip`; Linux: `onnxruntime-linux-x64-1.22.0.tgz`

## 4. Збірка
```
cmake -S . -B build -DORT_DIR=/шлях/до/розпакованого/onnxruntime-osx-x86_64-1.22.0
cmake --build build
```
(на Apple Silicon додайте `-DCMAKE_OSX_ARCHITECTURES=arm64`). Результат для програми: `build/libbeatcore_c.dylib` (на Linux `.so`) і тека `models/`.

## 5. Перевірка (необов'язково)
```
./build/meter_test tests/data/meter       # має закінчитись ALL PASSED
./build/stems_engine_test                 # ALL PASSED
./build/sounds_test                       # ALL PASSED
./build/engine_test                       # ENGINE TEST PASSED
```

## 6. Далі
Збирайте програму з архіву `ritmtrener-tauri.zip` (див. його `СКЛАДАННЯ.md`). При першому запуску програма попросить обрати цю теку `beat-core` (де є `build/` і `models/`).
Докладний опис ядра: `README.md`.
