# Як отримати установочний файл для Windows через GitHub

Усе вже підготовлено: ядро (C++), програма (Tauri) і файл збірки `.github/workflows/build-windows.yml`.
GitHub сам візьме віртуальний комп'ютер з Windows, збере ядро, завантажить нейромережі й створить інсталятор `.exe`
з усім потрібним усередині (окремо нічого встановлювати користувачу не треба).

## 1. Створіть репозиторій
1. На https://github.com натисніть **New repository**, назва, наприклад, `ritmtrener`. Виберіть **Private** (приватний).
2. Не додавайте README/.gitignore (залиште репозиторій порожнім).

## 2. Завантажте код
Розпакуйте архів і в терміналі в теці, де лежать `beat-core`, `ritmtrener-tauri` та прихована тека `.github`:
```
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/ritmtrener.git
git push -u origin main
```
(Завантажувати через браузер не радимо: прихована тека `.github` часто губиться.)

## 3. Запустіть збірку
1. У репозиторії відкрийте вкладку **Actions**.
2. Ліворуч виберіть **Windows installer** → **Run workflow** → **Run workflow**.
3. Перша збірка триває 25–50 хвилин (потім швидше, бо кешуються Rust і нейромережі).

## 4. Заберіть інсталятор
Коли збірка стане зеленою: відкрийте її та внизу в розділі **Artifacts** завантажіть
`RitmTrener-Windows-installer` (zip з файлом `RitmTrener_0.1.0_x64-setup.exe`). Запустіть його на Windows.
Windows SmartScreen може показати попередження, бо програма не має цифрового підпису: **Докладніше → Все одно запустити**.

## Якщо збірка червона
Відкрийте її, натисніть на крок, біля якого червоний хрестик, і скопіюйте кілька останніх десятків рядків журналу.
- Помилка на кроці **Build core**: проблема компіляції C++ на Windows (ядро я перевіряв крос-компіляцією, але не справжнім MSVC).
- Крок **Core smoke test** може бути жовтим: він необов'язковий і збірку не зупиняє.
- Помилка на **Download models**: тимчасово недоступний сервер із моделями, просто повторіть запуск.
- Помилка на **Build installer**: надішліть журнал.

## Де програма зберігає дані
Результати аналізу пісень (кеш) лежать у `%LOCALAPPDATA%\com.ritmtrener.app\cache`.

## Новинка: експорт треку
Кнопка зі стрілкою вниз поруч із назвою треку зберігає WAV із поточним темпом і вимкненими партіями
(за бажанням разом із метрономом). Партії мають бути розділені на вкладці «Розділення партій».
