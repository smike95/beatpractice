# Ритм-тренер — Tauri

Інтерфейс — ваш дизайн BeatPractice (React + Tailwind 3) у вікні програми. Увесь звук і аналіз робить C++ ядро `beat-core`.

## Що є
- Плейліст на всю висоту вікна (низ завжди видно), додавання кнопкою або перетягуванням файлів; обкладинки; налаштування кожного треку зберігаються.
- Верхня картка: обкладинка, «Виконавець — Назва» з кнопкою редагування (олівець), темп оригіналу, розмір (якщо змінний: «Змінний: 4/4, 3/4», від найчастішого),
  керування як у звичайних програвачах: ⏮ (на початок / попередній трек) ▶ ⏭ і кнопка «що робити після кінця» (зупинитись / знову цей трек з відліком / наступний трек),
  темп, Клік / Акцент / Відлік, візуальні долі, мікшер.
- Хвиля: сітка долей, номери тактів, мінікарта, масштаб, секції, цикл (добре видно: решта затемнюється, товсті межі).
- Вкладки: **Метроном та темп** (відлік, звук метронома, режим розпізнавання розміру, карта темпу), **Тренування** (до 3 циклів), **Розділення партій** (нейромережа: ударні, бас, інше, вокал; рівень, вимкнення, соло, швидкі набори «Без ударних» тощо).
- Три розміри шрифту на весь інтерфейс (15, 19 і 28 px).

## Оновлення ядра
Потрібен окремий архів `beat-core-update.zip` (розділення партій, розпізнавання розміру, звуки метронома). Без нього програма працює, але ці можливості неактивні.

## Встановлення (один раз)
Node.js (LTS) з https://nodejs.org і Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh` (потім новий Термінал).

## Запуск / оновлення
Зупиніть стару програму (Ctrl+C), розпакуйте архів поверх проєкту:
```
cd ritmtrener-tauri
npm install
npm run tauri dev
```

## Що перевірити
1. Складний трек: вкладка «Метроном та темп» → «Розпізнавання розміру»: Авто / Чутливо / Лише 3 і 4 долі. Чи правильні тепер розмір і темп?
2. Розділення партій (після оновлення ядра й завантаження моделі): час, якість «Без ударних».
3. Редагування треку (олівець): виконавець, назва, обкладинка.
4. Керування: ⏮ ▶ ⏭ і кнопка після кінця; плейліст на всю висоту; цикл на хвилі; шрифти й закруглення.
